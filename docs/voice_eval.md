# 人物区分度盲测（v2.25）

真实模型盲测尚未执行。脚本已用假模型验证：每人三个场景，台词去名、顺序打乱，正确标签不会发送给评审。

| 指标 | 结果 |
|---|---|
| 带档案人物数 | 待选择存档（至少 4 人） |
| 猜中率 | 待实测 |
| 随机猜中率 | 1 / 实际人物数 |
| 最容易混淆的两人 | 待实测 |

由作者手动执行（会产生 API 费用）：

```bash
.venv/bin/python scripts/voice_blind_test.py --slot <槽名>
```

每位角色生成三句台词，每句再评审一次，即通常共 `6 × 人物数` 次请求。脚本只读 JSON 存档；匿名卡片、台词、逐句猜测与指标保存到 `docs/voice_runs/<时间>/`，成功后把报告追加到本文件。人物不足或无密钥时给出提示，不发起请求。

5 人时猜中率至少 70% 是参考目标，尚未验证。模型同时担任生成者和评审者，结果是自动代理指标；需人工阅读，不能代替真实玩家对人物差异的判断。完整的人物知识隔离不在本次范围内。
