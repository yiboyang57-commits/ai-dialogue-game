由作者手动执行（会产生 DeepSeek API 费用）：

```bash
.venv/bin/python scripts/style_ab.py --script tests/fixtures/style_script.json
```

脚本用同一模板、20 条输入和代码随机种子分别运行两档，存档在临时目录隔离；评测原文与状态写入 `docs/style_ab_runs/<时间>/`，成功后把报告追加到本文件。普通叙事每档最多 20 次，判定、压缩及人物档案会增加调用；模型采样本身不保证可复现。若提前死亡，报告会标记剧本未完整完成，不将不等长样本冒充严格对比。

这里的“文学档”是当前版本不添加朴素语言节的对照，不是 v2.24 提示词的逐字复刻。朴素档套话率低于文学档一半只是目标，尚未验证；需结合原文判断是否自然、是否保持人物事实。

已有存档的只读统计：

```bash
.venv/bin/python scripts/style_report.py --slot <槽名>
```

指标按非空白字符计长度；句子按句号、问号、感叹号切分；台词支持「」、“”及英文双引号，检查其外侧 15 字，重叠套话不重复计数。没有数据库时只统计 JSON 中尚存的最近叙事，样本量会很小。
